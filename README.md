A GTA 6 meme entry for make.fun's "Post a GTA 6 meme on X" bounty. The work is the
post: a meme picture made with the make.fun mascot, posted publicly on X from a public
account, its text carrying make.fun and the entrant's play code. `main.ts` (Node 22,
standard library only) validates the post address in `POST.json`, normalises it to the
canonical form the gate parses, checks the meme picture it ships is really a picture,
and copies both through to `/output`.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
